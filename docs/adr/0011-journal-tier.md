# 11. The session journal is a second tier, not more kb

Date: 2026-09-24

## Status

Proposed

## Context

TODO: written by plan phase P5.

Capturing user/agent exchanges gives mnemos the working-memory tier it currently lacks,
the one mnemosyne's BEAM architecture provides. The risk is specific to mnemos: its
product claim is that every result is a document a human would cite. Transcripts are
high-volume, low-density, and carry the model's own wrong guesses. Indexed as ordinary kb
documents they would compete with ADRs in the same result set and erode the property that
distinguishes mnemos from an opaque-row memory store.
